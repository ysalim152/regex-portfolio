Recherche de Mots Dupliqués (SQL)

Retour à l'accueil

Objectif

Cet exemple montre comment utiliser une référence arrière (backreference) en SQL pour trouver des mots qui se répètent consécutivement. C'est une technique très utile pour le nettoyage de données textuelles.

La requête ci-dessous sélectionne les commentaires qui contiennent un mot répété, comme "le le".

La requête SQL

Note : En SQL, les barres obliques inverses dans la chaîne de regex doivent souvent être échappées. Ainsi, \b devient \\b et \1 devient \\1.


SELECT * FROM commentaires WHERE contenu REGEXP '\\b(\\w+)\\s+\\1\\b';

Détail de l'expression régulière : \b(\w+)\s+\1\b

  • \b : Ancre de "limite de mot" (word boundary). Assure qu'on ne capture pas une partie d'un mot plus long.
  • (\w+) : Groupe de capture n°1. Capture un ou plusieurs "caractères de mot" (lettres, chiffres, underscore).
  • \s+ : Correspond à un ou plusieurs caractères d'espacement (espace, tabulation, etc.).
  • \1 : Référence arrière (backreference). Correspond exactement au texte qui a été capturé par le premier groupe de capture.
  • \b : Une autre limite de mot pour marquer la fin du deuxième mot.

Exemple de table commentaires

Si on appliquait cette requête sur la table ci-dessous, seuls les enregistrements avec les ID 2 et 3 seraient retournés.
