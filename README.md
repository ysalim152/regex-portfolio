# Portfolio d'Expressions Régulières (REGEX)

Bienvenue sur ce portfolio dédié aux expressions régulières ! Ce projet rassemble une collection d'exemples pratiques pour démontrer l'utilisation et la puissance des REGEX dans différents contextes et langages de programmation.

## À propos du projet

Ce site a été conçu comme une ressource pédagogique et un portfolio pour illustrer la maîtrise des expressions régulières. Chaque exemple est présenté dans une page web interactive simple et stylisée.

## Exemples disponibles

Le portfolio inclut les démonstrations suivantes :

### Exemples en PHP

*   **CODE-POSTAL.php** : Valide un code postal français (5 chiffres).
*   **PSEUDO.php** : Valide un pseudonyme (longueur et caractères autorisés).
*   **EMAIL.php** : Valide le format d'une adresse e-mail.
*   **URL.php** : Valide le format d'une URL (HTTP/HTTPS).
*   **TEL.php** : Valide un numéro de téléphone français.
*   **PREG_REPLACE.php** : Remplace du texte pour créer des liens cliquables.
*   **IMMA.php** : Valide une plaque d'immatriculation française (format SIV `AA-123-AA`).
*   **DATE.php** : Valide le format d'une date (`JJ/MM/AAAA`).
*   **PASSWORD.php** : Valide la robustesse d'un mot de passe (critères de complexité).
*   **HASHTAG.php** : Extrait tous les hashtags d'une chaîne de caractères.
*   **LOG_PARSER.php** : Analyse (parse) un fichier de log pour en extraire des informations structurées (IP, statut, etc.).

### Exemples en JavaScript (interactifs)

*   **EMAIL_JS.html**: Valide une adresse e-mail en temps réel.
*   **TEL_JS.html**: Applique un masque de saisie pour un numéro de téléphone français.
*   **PASSWORD_JS.html**: Évalue la force d'un mot de passe en temps réel.
*   **USERNAME_JS.html**: Valide un pseudonyme en temps réel selon des règles spécifiques.
*   **HIGHLIGHT_JS.html**: Surligne dynamiquement du texte correspondant à une recherche utilisateur.
*   **URL_PARSER_JS.html**: Décompose une URL en ses différentes parties (protocole, domaine, etc.).

### Exemples en SQL (MySQL/MariaDB)

*   **SQL_VOWEL.html**: Sélectionne des enregistrements où un champ commence par une voyelle.
*   **SQL_PRODUCT_CODE.html**: Valide un format de code produit (`ABC-1234`).
*   **SQL_DUPLICATE_WORDS.html**: Sélectionne des enregistrements contenant des mots répétés consécutivement.

## Comment utiliser ce projet ?

Pour tester les exemples PHP, vous aurez besoin d'un environnement de serveur local qui prend en charge PHP.

1.  **Prérequis** : Avoir un serveur local comme XAMPP, WampServer ou utiliser le serveur web intégré de PHP.

2.  **Installation** :
    *   Clonez ou téléchargez ce dépôt.
    *   Placez tous les fichiers dans le répertoire racine de votre serveur web (par exemple, `htdocs` pour XAMPP).

3.  **Lancement** :
    *   Démarrez votre serveur Apache et PHP.
    *   Ouvrez votre navigateur et accédez à `http://localhost/` (ou au sous-dossier où vous avez placé les fichiers).
    *   La page `index.html` s'affichera, vous permettant de naviguer entre les différents exemples.
