Recherche de Noms par Voyelle (SQL)

Retour à l'accueil

Objectif

Cet exemple montre comment utiliser l'opérateur REGEXP en SQL (compatible MySQL/MariaDB) pour filtrer des résultats en fonction d'un modèle simple.

La requête ci-dessous sélectionne tous les utilisateurs dont le champ nom commence par une voyelle (a, e, i, o, u). Par défaut, REGEXP est insensible à la casse.

La requête SQL


SELECT * FROM utilisateurs WHERE nom REGEXP '^[aeiou]';

Détail de l'expression régulière : ^[aeiou]

  • ^ : Ancre. Indique que le modèle doit correspondre au début de la chaîne de caractères.
  • [aeiou] : Classe de caractères. Indique que le caractère suivant doit être l'une des voyelles listées.

Combinés, ces éléments signifient "la chaîne doit commencer par une voyelle".

Exemple de table utilisateurs

Si on appliquait cette requête sur la table ci-dessous, seuls les enregistrements pour 'Alice' et 'Éric' seraient retournés.


+----+--------+
| id | nom    |
+----+--------+
| 1  | Bob    |
| 2  | Alice  |
| 3  | Charlie|
| 4  | Éric   |
+----+--------+
