Parties extraites :

Le code JavaScript utilisé

Ce script utilise une expression régulière avec des groupes de capture nommés (?<nom>...) pour extraire facilement chaque partie d'une URL. La méthode .exec() retourne un objet de correspondance dont la propriété .groups contient les parties extraites.


const urlInput = document.getElementById('url-input');
const partsDiv = document.getElementById('url-parts');

const urlRegex = /^(?https?:\/\/)?(?[^/:]+)(?::(?\d+))?(?\/[^?#]*)?(?\?[^#]*)?(?#.*)?$/;

urlInput.addEventListener('input', () => {
    const url = urlInput.value;
    const match = urlRegex.exec(url);

    if (match && match.groups) {
        // On filtre les groupes qui sont undefined pour un affichage plus propre
        const capturedParts = Object.fromEntries(
            Object.entries(match.groups).filter(([key, value]) => value !== undefined)
        );
        partsDiv.textContent = JSON.stringify(capturedParts, null, 2);
    } else {
        partsDiv.textContent = 'URL invalide ou non analysable...';
    }

    if (url.trim() === '') {
        partsDiv.textContent = '';
    }
});
