Une collection d'exemples pratiques pour maîtriser les REGEX dans différents langages.

Exemples en SQL (MySQL/MariaDB)

Rechercher des noms commençant par une voyelle

Cette requête sélectionne les utilisateurs dont le nom commence par une voyelle (insensible à la casse avec `REGEXP` par défaut).

SELECT * FROM utilisateurs WHERE nom REGEXP '^[aeiou]';

Valider un format de code produit

Cette requête trouve les produits avec un code au format 'ABC-1234'.

SELECT * FROM produits WHERE code_produit REGEXP '^[A-Z]{3}-[0-9]{4}$';
