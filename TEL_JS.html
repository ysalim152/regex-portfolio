Le code JavaScript utilisé

Ce script amélioré applique un masque de saisie tout en conservant la position du curseur pour une expérience utilisateur fluide. À chaque modification, il nettoie l'entrée pour ne garder que les chiffres, la reformate (XX XX XX XX XX), puis recalcule et replace intelligemment le curseur, permettant à l'utilisateur d'éditer le numéro à n'importe quel endroit sans que le curseur ne saute à la fin.


const phoneInput = document.getElementById('phone');
const rawValueDisplay = document.getElementById('raw-value');

phoneInput.addEventListener('input', (e) => {
    const input = e.target;
    const originalValue = input.value;
    const cursorPosition = input.selectionStart;

    // 1. Compter le nombre de chiffres avant le curseur pour le repositionner plus tard.
    const digitsBeforeCursor = originalValue.slice(0, cursorPosition).replace(/\D/g, '').length;

    // 2. Nettoyer la valeur pour ne garder que les chiffres et la limiter.
    let digits = originalValue.replace(/\D/g, '');
    digits = digits.substring(0, 10);
    rawValueDisplay.textContent = digits;

    // 3. Formater la chaîne de chiffres avec des espaces.
    const formatted = digits.match(/(\d{1,2})/g);
    const formattedValue = formatted ? formatted.join(' ') : '';
    
    // 4. Mettre à jour la valeur de l'input.
    input.value = formattedValue;

    // 5. Calculer la nouvelle position du curseur.
    // On parcourt la nouvelle chaîne formatée et on s'arrête après avoir passé
    // le même nombre de chiffres qu'il y avait avant le curseur à l'origine.
    let newCursorPosition = 0;
    let digitsCounted = 0;
    for (const char of formattedValue) {
        if (digitsCounted === digitsBeforeCursor) {
            break;
        }
        if (/\d/.test(char)) {
            digitsCounted++;
        }
        newCursorPosition++;
    }

    // 6. Repositionner le curseur.
    input.setSelectionRange(newCursorPosition, newCursorPosition);
});
