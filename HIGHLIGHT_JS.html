Surlignage de Texte par Recherche (JavaScript)

Retour à l'accueil

Les expressions régulières, souvent abrégées en "regex" ou "regexp", sont une séquence de caractères qui définit un modèle de recherche. Elles sont principalement utilisées pour la recherche et la manipulation de chaînes de caractères.

Maîtriser les regex est une compétence précieuse pour tout développeur. Une regex peut valider une adresse e-mail, extraire des données d'un fichier log, ou, comme dans cet exemple, trouver toutes les occurrences d'un mot dans un texte. La puissance des regex réside dans leur flexibilité.

Le code JavaScript utilisé

Ce script utilise une expression régulière construite dynamiquement à partir de la saisie de l'utilisateur pour trouver et surligner toutes les correspondances. L'expression est créée avec les indicateurs g (global) et i (insensible à la casse).


const searchInput = document.getElementById('search-input');
const searchText = document.getElementById('search-text');
const originalText = searchText.innerHTML;

// Fonction pour échapper les caractères spéciaux pour la regex
function escapeRegex(string) {
    return string.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
}

searchInput.addEventListener('input', () => {
    const searchTerm = searchInput.value;

    if (searchTerm.trim() === '') {
        searchText.innerHTML = originalText;
        return;
    }

    const escapedTerm = escapeRegex(searchTerm);
    const regex = new RegExp(escapedTerm, 'gi');

    // On utilise .replace() pour envelopper chaque correspondance dans une balise <mark>
    const newText = originalText.replace(regex, (match) => `<mark>${match}</mark>`);
    
    searchText.innerHTML = newText;
});
