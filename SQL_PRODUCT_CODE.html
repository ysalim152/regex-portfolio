Validation d'un Code Produit (SQL)

Retour à l'accueil

Objectif

Cet exemple montre comment utiliser REGEXP pour valider un format de chaîne de caractères strict dans une base de données SQL.

La requête ci-dessous sélectionne tous les produits dont le code_produit correspond exactement au format 'trois lettres majuscules, un tiret, quatre chiffres'.

La requête SQL


SELECT * FROM produits WHERE code_produit REGEXP '^[A-Z]{3}-[0-9]{4}$';

Détail de l'expression régulière : ^[A-Z]{3}-[0-9]{4}$

  • ^ : Ancre de début de chaîne.
  • [A-Z]{3} : Correspond exactement à trois lettres majuscules (de A à Z).
  • - : Correspond au caractère littéral du tiret.
  • [0-9]{4} : Correspond exactement à quatre chiffres (de 0 à 9).
  • $ : Ancre de fin de chaîne.

Les ancres ^ et $ sont cruciales ici pour s'assurer que la chaîne entière correspond au modèle, et pas seulement une partie de celle-ci.

Exemple de table produits

Si on appliquait cette requête sur la table ci-dessous, seul l'enregistrement pour 'LIV-4096' serait retourné.


+----+--------------+
| id | code_produit |
+----+--------------+
| 1  | LIV-4096     |
| 2  | JEU-123      |
| 3  | MUS-98765    |
| 4  | ABC-DEFG     |
+----+--------------+
