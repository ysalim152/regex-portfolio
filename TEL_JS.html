Le code JavaScript utilisé

Ce script écoute l'événement input. À chaque saisie, il nettoie la valeur pour ne garder que les chiffres (avec .replace(/\D/g, '')), puis la reformate pour correspondre au format standard des numéros français (groupes de 2 chiffres séparés par des espaces).


const phoneInput = document.getElementById('phone');
const rawValueDisplay = document.getElementById('raw-value');

phoneInput.addEventListener('input', (e) => {
    // 1. On ne garde que les chiffres (\D signifie "tout ce qui n'est pas un chiffre")
    let digits = phoneInput.value.replace(/\D/g, '');

    // 2. On limite à 10 chiffres
    digits = digits.substring(0, 10);
    rawValueDisplay.textContent = digits;

    // 3. On applique le formatage (ex: 0123456789 -> 01 23 45 67 89)
    // On utilise .match() pour découper la chaîne en groupes de 1 à 2 chiffres.
    const formatted = digits.match(/(\d{1,2})/g);

    // 4. On met à jour la valeur de l'input avec les groupes joints par un espace
    if (formatted) {
        phoneInput.value = formatted.join(' ');
    } else {
        phoneInput.value = '';
    }
});
