Validation de Pseudonyme en Temps Réel (JavaScript)

Retour à l'accueil

Le code JavaScript utilisé

Ce script valide un pseudonyme en temps réel en se basant sur les règles suivantes :

  • Doit contenir entre 3 et 15 caractères.
  • Doit commencer par une lettre minuscule.
  • Peut contenir des lettres minuscules, des chiffres, des tirets (-) et des underscores (_).
  • Ne doit pas se terminer par un tiret ou un underscore.

L'expression régulière utilisée pour valider ces règles est : /^[a-z][a-z0-9_-]{1,13}[a-z0-9]$/


const usernameInput = document.getElementById('username');
const messageDiv = document.getElementById('validation-message');

// Regex pour la validation du pseudo
const usernameRegex = /^[a-z][a-z0-9_-]{1,13}[a-z0-9]$/;

usernameInput.addEventListener('input', () => {
    const username = usernameInput.value;

    if (username === "") {
        messageDiv.textContent = "";
        usernameInput.style.borderColor = '#ccc'; // Couleur par défaut
        return;
    }

    if (usernameRegex.test(username)) {
        messageDiv.textContent = 'Pseudonyme valide !';
        messageDiv.className = 'validation-message valid';
        usernameInput.style.borderColor = 'var(--valid-color)';
    } else {
        messageDiv.textContent = 'Pseudonyme invalide...';
        messageDiv.className = 'validation-message invalid';
        usernameInput.style.borderColor = 'var(--invalid-color)';
    }
});
